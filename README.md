# RichpTV

An IPTV player for Fire TV, Google TV / Android TV and Android phones, by RichpProductions.
You add your own M3U link or Xtream login. The app has no channels of its own.

## Features
- Live TV, Movies, Series, Favorites, Search, Settings
- Categories with counts, channel logos, movie posters
- Now / Next TV guide while browsing live channels (Xtream)
- Up / Down to change channels while watching
- Resume movies and episodes, auto-play the next episode
- Audio track and subtitle picker
- Set up from your phone by scanning a QR code on the TV

## Getting the app
Every time code is pushed to GitHub, the "Build RichpTV APK" action builds the app.
The newest file is always at:

https://github.com/<your-username>/<repo-name>/releases/latest/download/RichpTV.apk

Type that link into the Downloader app on your Fire TV or Google TV to install it.
